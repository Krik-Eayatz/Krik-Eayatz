### Dotfiles:
This repository also includes my dotfiles and setup scripts for my linux and macos systems. Feel free to copy my configurations and use them on your systems.
I seperated my MacOS and Fedora setup, for better organization, even if most of the configuration files are the same. I also documented my minimal Fedora KDE installation and
all related setups like ssh, git, stow and ai containerization.

If you want to download the Repository without git installed on your system use the following command:

